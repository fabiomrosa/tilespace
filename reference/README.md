# The 2017 tile wall

`surface.js` is where tilespace comes from: the jQuery and TweenMax tile wall of 2017. It is kept
here as a reference, not run, built or linted.

Its layout was formatted by Biome (spacing, indentation, quotes, semicolons, trailing commas,
redundant parentheses), and the names of the client and the agency it was made for were replaced by
generic ones (`App`, `AppSession`). Otherwise its code and comments are as they were. `docs/ARCHITECTURE.md` "Lessons from the
2017 wall" says what it got right and what tilespace does differently.
